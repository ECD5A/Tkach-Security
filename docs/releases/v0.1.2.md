# Tkach Security v0.1.2

Tkach Security v0.1.2 is a coordinated adapter and distribution hardening
release. The frozen Strong Core security contract is unchanged; the release
updates every public package and distribution channel to the same version.

## Highlights

- Align the default bounded exchange deadline at 35 seconds across Rust,
  Python, Node.js, Go, and MCP, with no automatic retries.
- Add slow-response and terminal-outcome regression coverage, including the
  explicit `outcome_unknown` classification that must never be retried.
- Publish separate `/healthz` liveness and `/readyz` admission signals. The
  runtime reports shutdown and non-evicting replay-ledger exhaustion as
  not-ready without discarding replay history.
- Keep the useful protected-effect Golden Case executable and run it on every
  supported CI platform. Build fuzz targets before their bounded smoke budget,
  cap per-input time and RSS, and retain failure artifacts.
- Refresh transitive `rustls` to `0.23.45`, closing RUSTSEC-2026-0285.
- Update the seven Rust crates, npm client, PyPI client, MCP metadata, signed
  release archives, and multi-architecture GHCR image to `0.1.2`.

## Verification

The release gates cover Rust formatting, clippy, debug/release tests and
documentation, dependency audit and license policy, SDK contract checks,
Python/Node/Go adapters, deterministic packaging, Golden Case execution,
bounded fuzz smoke, native archive smoke tests, checksums, Sigstore bundles,
and GitHub build attestations.

The deployment boundary remains local and loopback-only by default. This
release does not add a public gateway, TLS termination, Streamable HTTP,
process isolation, hosted service, or generic executor.

## Русский

Tkach Security v0.1.2 — согласованный релиз усиления адаптеров и поставки.
Контракт безопасности замороженного Strong Core не изменён; все публичные
пакеты и каналы распространения получают одну версию `0.1.2`.

- Единый ограниченный таймаут обмена 35 секунд для Rust, Python, Node.js, Go и
  MCP без автоматических повторов.
- Проверки медленных ответов и терминальных исходов, включая
  `outcome_unknown`, который нельзя повторять автоматически.
- Разделение liveness `/healthz` и admission readiness `/readyz`; история
  replay не очищается при заполнении.
- Golden Case запускается на всех платформах CI; fuzz-цели сначала собираются,
  затем выполняются в ограниченном режиме с сохранением артефактов ошибок.
- `rustls` обновлён до `0.23.45` для закрытия RUSTSEC-2026-0285.
