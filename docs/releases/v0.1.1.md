This release hardens the distributed Strong Core without changing its frozen
security contract. Supported public distribution channels use the same
`0.1.1` version and protected release path.

## Highlights

- Seven Rust crates were published on crates.io at `0.1.1`.
- `tkach-security-client@0.1.1` was published on npm and PyPI.
- `io.github.ECD5A/tkach-security@0.1.1` was registered in the Official MCP
  Registry for local stdio operation.
- The public GHCR image supports Linux amd64/arm64 and includes GitHub build
  provenance.
- Linux, macOS, and Windows archives include SHA-256 manifests, keyless
  Sigstore bundles, and GitHub build provenance.
- Windows archives preserve conventional `.exe` filenames.
- Package publication is protected by reviewed GitHub environments and
  short-lived OIDC credentials.

## Quick start

```console
cargo install tkach-cli --locked
tkach init my-agent
tkach check my-agent/.tkach/request.json
tkach run --demo
```

## Published surface

The verified OCI index is
`ghcr.io/ecd5a/tkach-security@sha256:7042c4292537d24a7d0c204751c340ded8aa89a3faae1aac8c4cab6804c3354c`.

The model remains untrusted data and cannot mint authority. The deployment
boundary remains non-root and loopback-only by default. This release did not
provide a public internet gateway, TLS termination, Streamable HTTP, a cloud
control plane, host/OS compromise protection, or a generic executor. MCP
remained a local stdio adapter over a separately started Tkach runtime.
