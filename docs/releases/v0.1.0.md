The first public Strong Core distribution: a fail-closed security boundary
for AI agents and compromised model output.

## Highlights

- Seven Rust crates were published on crates.io: `tkach-core`,
  `tkach-gateway`, `tkach-http`, `tkach-client`, `tkach-mcp`, `tkach-cli`,
  and `tkach-provider-openai`.
- The `tkach` CLI provided bounded `init`, strict `check`, the offline Golden
  Case, and loopback-only runtime commands.
- Thin Rust, Python, JavaScript, Go, and MCP adapters used the same
  language-neutral HTTP contract.
- The Golden Case demonstrated useful output release while a compromised
  provider's protected-write proposal was denied before executor invocation.
- Linux, macOS, and Windows artifacts were verified with SHA-256 manifests,
  keyless Sigstore signatures, and GitHub build attestations.

## Quick start

```console
cargo install tkach-cli --locked
tkach init my-agent
tkach check my-agent/.tkach/request.json
tkach run --demo
```

## Published surface

- JavaScript transport adapter: `tkach-security-client@0.1.0` on npm.
- Linux amd64/arm64 OCI image on GHCR, with build attestation:
  `ghcr.io/ecd5a/tkach-security@sha256:6e9f7e815a24385ca8e2ed6a3851ca7ab55d48410aad0167a63402149c64ed0f`.
- Local stdio MCP server: `io.github.ECD5A/tkach-security` in the Official
  MCP Registry.

The default runtime remained loopback-only and fail-closed. This release did
not provide a public internet gateway, TLS termination, PyPI package, or
Streamable HTTP service.
